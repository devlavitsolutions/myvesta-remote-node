LiteSpeed Cache Plugin Version Manager

Set Active Version

Sets the LiteSpeed Cache plugin version to be used in all future "Enable" operations.
(There may be a delay before new versions appear)

Force Version Change For All Existing Installations

Upgrades active LiteSpeed Cache plugins matching the selection in the "From Version" list to the version chosen under "Upgrade To". Flagged installations will be skipped. (To ensure stability, there may be a delay before new LiteSpeed Cache plugin versions appear in this list)

Flagged installations will be skipped automatically.
